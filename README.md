# Hameedcode — Personal Portfolio Website

A personal portfolio website built with **Astro** and **TailwindCSS**, showcasing my projects, skills, and experience as a Software Engineer.

---

## 🚀 Tech Stack

- **Framework:** [Astro](https://astro.build/)
- **Styling:** [TailwindCSS](https://tailwindcss.com/)
- **Animations:** [GSAP](https://gsap.com/), [Motion](https://motion.dev/)
- **Language:** TypeScript / JavaScript
- **Database (Projects):** Firebase
- **Deployment:** Vercel / Netlify

## 🛠️ Getting Started

1. **Install Dependencies**
```bash
pnpm install
```

2. **Run the development server**
```bash
pnpm dev
```

3. **Build for production**
```bash
pnpm build
```

> Requires Node.js >= 20 and pnpm >= 9
